# Phoebe & Selene Photography

A static website ready for GitHub Pages. No installation or build step is required.

## Upload to GitHub

1. Create a repository and upload the contents of this folder so `index.html` is at the repository root.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select your main branch and **/ (root)**, then save.

All image, font, style and script paths are relative, so this works with a GitHub Pages repository URL or a custom domain.

## Included version

Includes the five newly supplied photographs and the dark overlay above the opening slideshow photos and below the lettering. The original website layout is retained. The red envelope below the contact form is removed. Photo reuse is limited to twice per image, the final postcard photo is the museum gallery, and original museum images display in black and white. Color source files are preserved.

The inquiry form is a visual preview: email delivery is not connected, and the page reports that entries are not sent or saved. Connect a form service or backend before accepting inquiries.

## Local preview

Open `index.html`, or serve this folder with any static web server.

## Assets

Photographs and custom graphics belong to their respective owners. This package is provided for the owner’s website; it does not grant reuse rights to others. Retain the included font documentation.

## Render

Create a Static Site. Leave the build command blank and set the publish directory to `.`. No start command is required.
