# Phoebe & Selene Photography

Upload this folder’s contents to the repository root. No build is required.

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
Render: create a Static Site, leave Build Command blank, Publish Directory `.`. No start command.

The short form opens a prefilled text draft to 786-941-JPEG (786-941-5734). Visitors review and send it in their messaging app. Copy note is available for computers. The website does not send or store the form itself. Call and Text buttons open the corresponding device app. Actual SMS handoff depends on the device having a messaging app configured.

Includes updated mobile styling, centered color collection photo, simple botanical process icons, museum collage and centered Medea cutout, and approved logo placements. Original color images remain preserved; museum photographs are rendered monochrome on the page.

Local preview: `python3 -m http.server 4321`, then visit http://localhost:4321.

Photographs and illustrations remain the owner’s property. Keep the included font documentation.
